# HANDOVER.md — Asankary white-label clone

Asankary is an independent white-label clone of the Haryad Autoparts app (React Native 0.81 / Expo SDK 54, New Architecture, TypeScript strict). This repo was created clean-room (no shared git history) and rebranded end-to-end. It boots on placeholder infrastructure with graceful failures until the real accounts/keys are wired.

**Companion docs:** `PURGED.md` (what was deleted + Haryad secrets to rotate), `SETUP_CHECKLIST.md` (ordered console steps to stand up every service).

---

## What changed, per phase

**Phase 0 — clean-room purge** (`cb6d747`)
Copied the working tree without `.git`; deleted all committed secrets, keystores, Firebase configs, production data dumps, 42 one-off scripts, native `android/`+`ios/` (regenerated by prebuild), and 4 dead screens. Added `.gitignore`, `.env.example` ×2, `PURGED.md`. Moved the hardcoded Gemini key to `process.env`.

**Phase 1 — rebrand → Asankary** (`63fb8f0`)
Identity (name/slug/scheme/bundle `com.asankary.app`, version 1.0.0). Deep links `asankary://` + `ASANKARY_DOMAIN_TBD`. Dropped Volvo positioning; chatbot/AI reframed as a general store assistant. Central `BRAND` config block. De-branded all screens, 3 locales, docs, backend fns. Functional renames: auth internal domains `@haryad*`→`@asankary*`, storage key prefix `@haryad_`→`@asankary_` (**invalidates old stored sessions — expected for a new app**). Recreated `OnboardingScreen` (it is used by `App.tsx`; wrongly deleted in Phase 0). Neutralized Haryad FB/Google/EAS identifiers to placeholders.

**Phase 2 — env wiring** (`cd783a3`)
All backend config reads from `EXPO_PUBLIC_*` env via central accessors in `src/constants/config.ts` (`SUPABASE_CONFIG`, `GOOGLE_MAPS_API_KEY`, `GOOGLE_AUTH`, `FIREBASE_PROJECT_ID`, `FIREBASE_FUNCTIONS_URL`). Removed the still-hardcoded live Haryad Supabase URL/anon key, the stale `truckserviceapp-f9712` project, Google OAuth client ids, Cloudflare-worker + SQL project refs, and the tracked `supabase/.temp` project pointer.

**Phase 3 — Amber Retail theme + assets** (`d450127`)
New default presets `amber-retail` (light) + `amber-retail-dark` (warm orange `#F5A00A` on neutral surfaces). `ThemeProvider` defaults, static `theme.ts`, and `app.config.ts` native colors all aligned (native splash/adaptive-icon now match runtime UI). Regenerated placeholder icon set (amber "A" glyph) at all existing filenames/sizes.

**Phase 4 — Home + Categories redesign + tab bar** (aynAlfahad style)
Re-skinned the shared `MasonryProductCard` (rounded white card, brand line, dark price, full-width orange "Add to Cart" / gray "Out of stock" pill, neutral image-off placeholder, amber heart) — this re-skins both screens at once. New shared `SectionHeader` + `BrandTile`. Home: greeting header + hero carousel + client-side-derived "Our Brands" + brand-spotlight carousels + New Arrivals grid. Categories: count + filter header, BrandTile category tiles, 2-col card grid. Custom `AnimatedTabBar` restyled to the floating raised-active-tab look. All data hooks, nav targets, RTL, i18n, and theme-preset (light/dark) support preserved. No new backend queries.

## Remaining setup (see SETUP_CHECKLIST.md for exact steps)
1. Supabase: new project → env + secrets → port schema (`supabase/migrations` + `schema.sql`) → deploy 12 edge functions.
2. Firebase: new project → `google-services.json` + `GoogleService-Info.plist` (git-ignored, needed for prebuild) → phone auth + FCM → deploy `functions/`.
3. Google Maps (3 slots), Google Sign-In (reversed + web/ios client ids), Apple Sign-In, Facebook app.
4. EAS `eas init` under the Asankary account → new keystore (never commit) → fill `projectId`/`updates.url`/`API_URL`.
5. Bunny CDN, QiCard merchant + deploy Cloudflare worker on the real domain, OTPIQ/Twilio, OpenAI + Gemini keys.

**Note:** `expo prebuild` needs `google-services.json` + `GoogleService-Info.plist` present (create the new Firebase ones, or temporary placeholders, before prebuilding).
