## 📱 App Store Submission Checklist

### Google Play Store Requirements

#### ✅ **Technical Requirements**
- [ ] Target API Level 34 (Android 14) or higher
- [ ] 64-bit architecture support
- [ ] App Bundle (.aab) format for upload
- [ ] Privacy Policy URL provided
- [ ] Data safety form completed
- [ ] App content rating completed
- [ ] Store listing in required languages

#### ✅ **App Content**
- [ ] No prohibited content (violence, adult content, etc.)
- [ ] Functional app (no placeholders or demos)
- [ ] Proper app permissions requested
- [ ] User data handling disclosed
- [ ] In-app purchases properly implemented

#### ✅ **Store Listing**
- [ ] App title (max 50 characters): "Haryad Auto Parts - Truck Parts"

- [ ] Full description (max 4000 characters) - detailed, keyword-rich
- [ ] App icon (512x512 px, PNG)
- [ ] Feature graphic (1024x500 px)
- [ ] Phone screenshots (min 2, max 8)
- [ ] 7-inch tablet screenshots (optional but recommended)
- [ ] 10-inch tablet screenshots (optional but recommended)

#### ✅ **Technical Requirements**
