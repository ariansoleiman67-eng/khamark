# 🚀 Khamark - App Store & Marketing Preparation Checklist

## 📱 App Store Submission Checklist

### Google Play Store Requirements

#### ✅ **Technical Requirements**
- [ ] Target API Level 34 (Android 14) or higher
- [ ] 64-bit architecture support
- [ ] App Bundle (.aab) format for upload
- [ ] Privacy Policy URL provided
- [ ] Data safety form completed
- [ ] App content rating completed
- [ ] Store listing in required languages

#### ✅ **App Content**
- [ ] No prohibited content (violence, adult content, etc.)
- [ ] Functional app (no placeholders or demos)
- [ ] Proper app permissions requested
- [ ] User data handling disclosed
- [ ] In-app purchases properly implemented

#### ✅ **Store Listing**
- [ ] App title (max 50 characters): "Khamark - Mobile Accessories & Electronics"
- [ ] Short description (max 80 characters): "Shop electronics and accessories with fast delivery across Iraq"
- [ ] Full description (max 4000 characters) - detailed, keyword-rich
- [ ] App icon (512x512 px, PNG)
- [ ] Feature graphic (1024x500 px)
- [ ] Phone screenshots (min 2, max 8)
- [ ] 7-inch tablet screenshots (optional but recommended)
- [ ] 10-inch tablet screenshots (optional but recommended)

### Apple App Store Requirements

#### ✅ **Technical Requirements**
- [ ] iOS 14.0+ minimum deployment target
- [ ] Built with Xcode 15 or later
- [ ] App Store Connect submission
- [ ] TestFlight beta testing completed
- [ ] App Review Guidelines compliance

#### ✅ **App Content**
- [ ] Human Interface Guidelines compliance
- [ ] No usage of private APIs
- [ ] Proper app permissions with usage descriptions
- [ ] Privacy Policy accessible from app
- [ ] Terms of Service available

#### ✅ **Store Listing**
- [ ] App name (max 30 characters)
- [ ] Subtitle (max 30 characters)
- [ ] Description (max 4000 characters)
- [ ] Keywords (max 100 characters)
- [ ] App icon (1024x1024 px)
- [ ] Screenshots for all supported device sizes
- [ ] App preview videos (optional but recommended)
